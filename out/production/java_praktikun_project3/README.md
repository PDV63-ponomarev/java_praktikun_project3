# Трекер задач
Бэкенд для трекера задач, отслеживающее их выполнение.  

Состояние задач: New, In Progress, Done  

Элементы задачи: 
- Название
- Описание
- Уникальный идентификатор
- Статус (NEW, IN_PROGRESS, DONE)

Есть три типа задачи: обычные, большие и подзадачи.  
Большие задачи (epic), содержат в себе подзадачи(substack).  
Условия:
- Каждая подзадача содержит информацию, в какой большой задаче состоит
- Каждая большая задача знает, какие подзадачи в ней находятся
- Завершение всех подзадач большой задачи, считается выполнением большой задачи

Функционал программы:
1) Хранить задачи всех типов
2) Методы для задач:
   1. Получения списка всех задач
   2. Удаление всех задач
   3. Получение задачи по идентификатору
   4. Создание задачи.
   5. Обновление задачи
   6. Удаление по идентификатору
3) Получения списка всех подзадач определенного epic
4) Управление статусами осуществляется по правилам:
   1. Статус задачи обновляется вместе с полным обновлением задачи.
   2. Для больших задач:
      - Если нет подзадача или все они имеют статус NEW, то статус задачи NEW
      - Если все подзадачи имеют статус DONE, то и epic имеет статус DONE
      - Во всех остальных случаях статус IN_PROGRESS
